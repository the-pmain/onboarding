# Onboarding

A blank, client-side React website built with Vite.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed in the terminal. Edit `src/App.jsx` to add content and `src/styles.css` to style it.

## Production build

```sh
npm run build
```

The static website is generated in `dist/`. No backend or server-side rendering is required.
